Features

Everything you need to find a rental

From automated scraping to smart notifications — SunnyNest handles the entire rental search pipeline.

🔍

Multi-Source Scraping

Fetches listings from Zillow, Craigslist, and Realtor.com using the adapter pattern. Each source has its own scraper with normalized output.

Zillow API Playwright Adapter Pattern
🗺️

Interactive Map View

Leaflet.js map with price-pill markers, school district boundary overlays, custom POI markers, and card-to-map synchronization.

Leaflet.js GeoJSON Price Pills
📧

Smart Notifications

Email alerts for new listings matching your criteria. Configurable AM/PM digest schedule with anti-spam guards and dedup-aware filtering.

Email Scheduled Filtered
🔄

Cross-Source Deduplication

Multi-signal scoring engine (address, price, beds, baths, sqft) detects duplicate listings across sources. Threshold-based with ≥75 match score.

Fuzzy Match Multi-Signal
📊

Admin Dashboard

5-page admin panel with system health, scrape analytics, API usage tracking (donut charts, sparklines), notification management, and settings.

Analytics Charts 5 Pages
⚡

Performance First

Lazy-loaded images, clustered map markers, HTMX-driven partial updates, and optimized queries. Search results load in under 2 seconds.

HTMX Lazy Load <2s
