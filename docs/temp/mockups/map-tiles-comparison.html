🏆 Recommended Approach

Phase 1 (now): Switch to OpenStreetMap Standard — zero cost, one-line change, immediate visual improvement.

Phase 2 (later): Upgrade to Stadia Outdoors — best free-tier quality, closest to Google Maps. Requires free Stadia account + API key.

200K tiles/month free tier is more than enough for a single-user local app.
